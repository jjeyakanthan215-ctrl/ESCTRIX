================================================================================
                              USER'S PLAN / VISION
================================================================================

The user's original plan was to build a premium, Instagram-inspired secure
messaging web application with the following goals:

  1. BRANDING
     - Name the app "ESCTRIX"
     - Create a custom logo (orbit/chat bubble/arrow icon + "ESCTRIX" text)
     - The app should feel modern, dark-themed, and professional

  2. USER AUTHENTICATION
     - Login and Registration pages (no Facebook login)
     - A one-click Privacy Policy / E2EE terms checkbox on login
     - Real-time username availability check (Instagram style: green tick or
       red cross as user types)
     - Forgot password using username + date of birth (no email required)
     - Human verification (checkbox confirmation in place of CAPTCHA)

  3. CHAT FEATURES
     - End-to-End Encrypted (E2EE) messaging
     - Add friends / friend requests / notifications
     - Direct messaging and group chats
     - Typing indicators, read receipts (✔✔), online/offline status
     - Emoji reactions on messages
     - Disappearing/self-destruct messages (countdown timer)
     - File/image sharing in chats (encrypted)

  4. PROFILE MANAGEMENT
     - Editable display name (profile name)
     - Editable username, bio, date of birth
     - Live preview of name changes while typing
     - Avatar system

  5. USER SETTINGS
     - Block / unblock users
     - Change password
     - Help & Support ticket submission
     - Theme selector (multiple chat color themes)

  6. ADMIN SYSTEM
     - Separate admin credentials (Esctrix215 / Jerry215)
     - Admin logs in from the SAME login page as regular users
     - Automatically redirected to admin panel after login
     - Admin panel styled in the same dark ESCTRIX theme
     - Admin can:
         * View all user accounts
         * Deactivate / terminate user accounts
         * Read and resolve support tickets
         * Manage friend requests, groups, block lists

  7. MOBILE-FRIENDLY
     - The app should work fully on mobile phones
     - Responsive bottom navigation, fullscreen chat on mobile
     - Touch-friendly UI

  8. CLEAN PROJECT
     - Remove unused files, legacy folders, IDE files, Python cache
     - Organized file structure
     - Version-controlled with Git

STEP 3: AUTHENTICATION SYSTEM
------------------------------------------------------------------------

  - Background: cyber-matrix grid with radial purple/cyan glow

  REAL-TIME USERNAME AVAILABILITY CHECKER (Instagram Style):
  - As user types in the username field during registration:
      * Green ✔ appears inside the input if username is AVAILABLE
      * Red ✘ appears inside the input if username is TAKEN or INVALID
      * Input border highlights green or red accordingly
      * Uses 400ms debounce to avoid excessive server calls
  - Backend endpoint: GET /api/check-username/?username=<value>
  - Returns: { "available": true/false }

  FORGOT PASSWORD (No Email Required):
  - User enters their username + date of birth
  - If both match a registered account, a session token is granted
  - User is then shown a new password form
  - Password reset is saved without any SMTP email server

================================================================================
                              API ENDPOINT REFERENCE
================================================================================

AUTHENTICATION:
  POST /api/login/              → Login user (returns is_admin flag)
  POST /api/register/           → Register new account
  GET  /api/check-username/     → Check username availability (live)
  GET  /api/logout/             → Log out user
  POST /api/forgot-password/    → Verify identity (username + DOB)
  POST /api/reset-password/     → Reset password after verification

PROFILE:
  POST /api/profile/update/     → Update username, display name, bio, DOB
  POST /api/profile/change-password/  → Change password
  GET  /api/profile/get/        → Get current user profile data

FRIENDS & SOCIAL:
  GET  /api/search/             → Search users by username or display name
  POST /api/friend-request/send/     → Send a friend request
  POST /api/friend-request/accept/   → Accept a friend request
  POST /api/friend-request/decline/  → Decline a friend request
  GET  /api/friend-requests/pending/ → List pending incoming requests

BLOCKING:
  POST /api/block/add/          → Block a user
  POST /api/block/remove/       → Unblock a user
  GET  /api/block/list/         → Get block list

CHAT HISTORY:
  GET  /api/chat/history/       → Load direct message history
  GET  /api/group/history/      → Load group message history

GROUPS:
  POST /api/group/create/       → Create a group chat
  GET  /api/group/list/         → List user's groups
  GET  /api/group/members/      → Get group members list

HELP & SUPPORT:
  POST /api/help/submit/        → Submit a support ticket
  GET  /api/help/list/          → List user's support tickets

ADMIN PANEL:
  ANY  /admin/                  → Django admin panel (staff only)

REAL-TIME (WebSocket):
  ws://host/ws/chat/<room_id>/  → E2EE Direct/Group chat WebSocket
  ws://host/ws/status/          → Online/offline presence tracking
