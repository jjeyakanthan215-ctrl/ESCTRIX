--- BACKEND SERVER (3 files) ---

1. requirements.txt
   Python package dependencies:
   - websockets         (WebSocket server)
   - argon2-cffi         (Password hashing)
   - PyJWT              (JWT token generation/validation)
   - aiosqlite          (Async SQLite)

2. database.py
   SQLite database layer with all CRUD operations:
   - User registration with username validation
   - Password hashing with Argon2id
   - Friend request management (send/accept/decline/remove)
   - User search (by username and display name)
   - Profile management (get/update)
   - Pending message storage for offline users
   - Login throttling (5 failures = 5 min lockout)

3. server.py
   AsyncIO WebSocket signaling server:
   - Listens on 0.0.0.0:8765
   - Connection map: {username: websocket}
   - JWT authentication on all messages
   - Heartbeat ping every 30 seconds
   - Rate limiting per IP
   - All message type handlers (see SERVER_PROTOCOL.txt)
   - Friend status push notifications
   - Call signaling relay (SDP, ICE candidates)
   - Offline message storage and delivery
   - Friendship enforcement for calls/messages

--- FLUTTER CLIENT - CORE (4 files) ---

4. main.dart
   App entry point:
   - MaterialApp with dark theme
   - Provider state management setup
   - Route definitions
   - Google Fonts (Inter) configuration
   - Initial auth check (auto-login if token exists)

5. crypto_utils.dart
   End-to-end encryption utilities:
   - AES-256-GCM encryption with random 12-byte IV per message
   - Encryption output: base64(IV || ciphertext || authTag)
   - Decryption: parse base64 → extract IV → decrypt → return plaintext
   - Shared secret key management

6. websocket_service.dart
   WebSocket connection manager:
   - Connect to ws://SERVER_IP:8765
   - Auto-reconnect with exponential backoff (1s → 2s → 4s → 8s → max 30s)
   - JSON message serialization/deserialization
   - JWT token attached to every message after login
   - Stream-based event system (StreamController) for incoming messages
   - Send message helper with automatic token injection

7. webrtc_service.dart
   WebRTC peer-to-peer connection manager:
   - ICE servers: Google STUN + Metered.ca TURN
   - Audio stream: Opus 8-16 kbps + DTX
   - SDP munging: force low bitrate + enable DTX
   - DataChannel: "textChat" for encrypted messages
   - Call states: Idle → Ringing → Connecting → Connected → Ended
   - Controls: mute, unmute, speaker toggle, call timer
   - ICE restart on network switch (WiFi ↔ Mobile)
   - Proper cleanup: dispose streams, connections, channels

8. auth_service.dart
   Authentication service:
   - register(username, displayName, password) → JWT
   - login(username, password) → JWT + profile + pending data
   - Store JWT + username in flutter_secure_storage
   - Auto-login on restart (validate stored token)
   - logout() → clear stored credentials
   - Check if logged in
