1. EXECUTIVE SUMMARY & ARCHITECTURE
--------------------------------------------------------------------------------
ESCTRIX Quantum combines the best UX and security paradigms of major communication platforms:
- Instagram Style: Search and connect by @username / Account ID, rich Profile Verification Cards, social bios, and photo avatars.
- WhatsApp Style: 1-to-1 WebRTC HD audio/video calls, WhatsApp voice note HUD with live waveform, pause/resume, audio preview before sending, read receipts (blue double ticks), and dynamic context menus.
- Telegram Style: Dual-pane desktop and mobile layout, collapsible sidebar, folder categorizations (All, Direct, Mesh, Saved Vault), group space hosting with PIN protection.
- Zero-Knowledge Security: Client-side AES-GCM 256-bit encryption in browser memory, DTLS/SRTP WebRTC peer-to-peer transport, ephemeral WebSocket signaling, zero plaintext storage on servers.
- Aura Neural AI: Integrated conversational AI companion, real-time vibe sentiment analysis, contextual smart replies, tone polisher, and chat summarization.

2. COMPLETED FEATURES & RECENT IMPLEMENTATIONS
--------------------------------------------------------------------------------

A. Stealth Admin Portal & Role-Based Isolation:
   - Zero public admin indicators anywhere on UI or public endpoints.
   - Admin account is `ESCTRIX_Admin` (Role: `admin`).
   - `search_users()` strictly filters out all accounts with `role == 'admin'` or usernames containing `admin`, making admin identities 100% invisible to regular user search.
   - `add_contact()` rejects adding admin accounts to public contacts lists.
   - Admin access routes:
     * Stealth URL: `/admin`
     * Settings Suite: "Admin Portal" button (only visible if logged-in user role is `admin`).
     * Keyboard Shortcut: `Ctrl + Shift + A` directly triggers the stealth admin portal.
     * Stealth Command Palette in chat: Typing `/admin` directly opens the console.

B. WhatsApp-Style Voice Note Suite:
   - Live recording HUD bar with pulsing recording dot and elapsed timer (`0:00`).
   - Real-time animated audio waveform visualization.
   - Discard / Trash button (`#voice-discard-btn`) to discard unwanted recordings.
   - Pause / Resume recording toggle (`#voice-pause-btn`).
   - Listen / Playback Preview button (`#voice-preview-btn`) to review audio before sending.
   - 1-Click Send button (`#voice-send-btn`).

C. Dynamic Glassmorphic Context Menu & Right-Click Lock:
   - Suppressed browser native right-click inspection menu (`e.preventDefault()`).
   - Added touch 500ms long-press trigger for mobile/tablet devices.
   - Dynamic contextual options:
     * On Message: Copy Text, Reply, Forward, Star to Vault, Delete for Me.
     * On Contact / Chat Item: View Profile Card, Pin Chat to Top, Mute Alerts, Clear History.
     * On General Canvas / Sidebar: Host Space, E2EE Key Verification, Settings Suite, Clear Chat.

D. In-App Custom Glass Dialogs (Zero Browser Popups):
   - Replaced all native `alert()`, `confirm()`, and `prompt()` with glassmorphic modal dialogs (`ESCTRIX.dialog.confirm`, `ESCTRIX.dialog.prompt`, `ESCTRIX.dialog.alert`).
   - Guarded with `style="display: none;"` to prevent flash of unstyled content (FOUC).

E. Zero-Scrollbar Global Aesthetic:
   - Universal CSS rule `* { scrollbar-width: none !important; -ms-overflow-style: none !important; }` and `::-webkit-scrollbar { display: none !important; }` applied across the entire app.

F. Responsive Design Alignment (Desktop & Mobile):
   - Desktop (>= 769px):
     * Sticky full-width glass header (`backdrop-filter: blur(24px)`).
     * Centered hero logo halo (`88px x 88px`), balanced typography, and 4-column capability grid.
     * Centered user identity card with inline action buttons.
   - Mobile (<= 768px):
     * Compact header automatically hides the bulky "MESH ACTIVE" badge to prevent colliding with "Get Started".
     * Full-width stacking action buttons (`Launch Workspace` & `Switch Identity`) for touch ergonomics.
     * Feature cards automatically reflow into a clean 1-column vertical feed.
     * Zero horizontal scrolling / overflow (`overflow-x: hidden; box-sizing: border-box`).

G. Automated Self-Healing PWA Cache Cleaner:
   - Injected critical inline guard CSS in `<head>` to enforce dimensions before external CSS loads.
   - Self-healing version comparator script (`CURRENT_VER = '2.1.1-quantum'`) detects stale versions in `localStorage` and automatically deletes outdated Service Worker caches (`caches.delete()`) and unregisters old service workers on client visit.
   - Cache-busting query strings (`?v=2.1.1`) appended to all stylesheets and scripts.

4. LOCAL RUNNING & TESTING COMMANDS
--------------------------------------------------------------------------------
To run the project locally on Windows PowerShell:
1. Start server:
   python server.py
   (Default port: http://127.0.0.1:8006)

2. Test API endpoints:
   python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8006/health').read())"

3. Test stealth search:
   python -c "import database; print('Admin search (should be empty):', database.search_users('admin'))"
