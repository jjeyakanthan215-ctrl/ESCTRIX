Security Features

Built Secure from the Ground Up

ESCTRIX was designed with privacy and security as core principles — not afterthoughts. Here is a complete overview of how we protect your data and communications.

Last updated: August 2026

Unlike many chat platforms, ESCTRIX cannot read your messages. All encryption keys are generated on your device and never transmitted to our servers.

1. End-to-End Encryption (E2EE)

Every message you send on ESCTRIX is end-to-end encrypted using the WebCrypto API (AES-GCM 256-bit). This means:

  • Messages are encrypted on your device before they are sent over the network.
  • Only the intended recipient can decrypt and read the message.
  • Not even ESCTRIX servers or administrators can read your messages.
  • Encryption keys are derived from your session — they never leave your device.
  • Group messages use per-group shared keys, regenerated on each session.

2. Password Security

  • Passwords are hashed using Django's PBKDF2 with SHA-256 — a military-grade standard.
  • Passwords are never stored in plain text — not even the admin can see them.
  • A unique cryptographic salt is applied per password to prevent rainbow table attacks.
  • Minimum password length of 8 characters is enforced during registration.

3. Secure Transport Layer

  • All HTTP traffic uses HTTPS (TLS 1.3) to encrypt data in transit.
  • WebSocket chat connections use WSS (WebSocket Secure) — the encrypted equivalent of WSS.
  • CSRF tokens are required on all state-changing requests, preventing cross-site request forgery.
  • Session cookies are HttpOnly and Secure — inaccessible to JavaScript and transmitted only over HTTPS.

4. Disappearing / Vanish Messages

ESCTRIX supports self-destructing messages that automatically delete after a set timer:

  • Timers: 10 seconds · 30 seconds · 1 minute · 1 hour · 1 day
  • Once a message expires, it is permanently deleted from the server database.
  • The timer countdown is visible to both sender and receiver in the chat bubble.
  • Vanish Mode ensures no permanent record of sensitive conversations.

5. Account Protection Features

  • Block users: Blocked users cannot send messages or view your profile.
  • Identity verification for password reset: Requires your username + date of birth — no email needed.
  • Admin account termination: Accounts violating policies can be disabled instantly.
  • Session-based reset tokens: Password reset tokens are tied to your browser session and expire when you close the tab.

6. Server & Database Security

  • Database access is restricted to the application server only — no public access.
  • Admin panel is accessible only with staff-level credentials.
  • Media files (shared images/attachments) are stored in a restricted directory, not publicly browsable.
  • All API endpoints validate user authentication before returning any data.

7. Real-Time Security Features

  • Online presence: Your online/offline status is only visible to your accepted friends.
  • Read receipts: Only shown to the sender of a message you have read.
  • Typing indicators: Only visible to the person you are chatting with in real time.
  • All WebSocket connections are authenticated — anonymous connections are rejected.

8. Report a Security Issue

If you discover a security vulnerability or suspicious activity on ESCTRIX, please report it immediately through:

  • The Help & Support button on the login page (select "Technical / app issue").
  • The Settings → Help & Support panel after logging in.
  • Directly contact the administrator at the admin portal.
We take all security reports seriously and aim to respond within 24 hours. Responsible disclosure is appreciated and will be acknowledged.
